# Enterprise ISO 27001:2022 Compliance Framework & SoA

## Project Overview
This project simulates the end-to-end information security management system (ISMS) implementation and audit readiness process for **NexusFin Technologies**, a growing cloud-native financial technology startup.

## Organizational Scope & Context
- **Industry:** Digital Payments & SaaS Cloud Infrastructure
- **Infrastructure:** 100% cloud-hosted (AWS us-east-1), utilizing remote-hybrid engineering teams and a central corporate office in Mumbai.
- **Objective:** Establish a comprehensive Statement of Applicability (SoA) mapping all essential Annex A security controls to internal administrative policies and technical artifact evidence to prepare for an external ISO 27001:2022 Stage 1 & Stage 2 audit.

## Project Artifacts
- `Statement_of_Applicability.xlsx` (The master 16-control SoA matrix covering Organizational, People, Physical, and Technological domains)
- Policy reference document templates and evidence mapping logs.

## Control Matrix Breakdown
The project covers core controls across the 4 ISO 27001:2022 Annex A domains:
1. **Organizational:** Policies, asset management, access control, and cloud service security.
2. **People:** Pre-employment screening, contracts, awareness training, and remote working guidelines.
3. **Physical:** Entry controls, physical monitoring, and off-premise asset safety.
4. **Technological:** Configuration management, data leakage prevention (DLP), network security, encryption standards, and secure coding pipelines.
